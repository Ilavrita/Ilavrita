# @ilavrita/console

Operator console for configuration visibility, Project administration, reindexing,
health and resource inspection (FR-041).

Not implemented yet. The console is deliberately subordinate to the HTTP API:
every operation it offers must also be reachable without it, so an operator is
never forced through a browser to run their deployment.

Accessibility target for core workflows is WCAG 2.2 AA (NFR-012).
