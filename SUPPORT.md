# Getting help

| I want to... | Go to |
| --- | --- |
| Ask a question or share what I am building | [Discussions](https://github.com/Ilavrita/Ilavrita/discussions) |
| Report something broken | [Bug report](https://github.com/Ilavrita/Ilavrita/issues/new?template=bug_report.yml) |
| Report a FHIR conformance deviation | [Conformance issue](https://github.com/Ilavrita/Ilavrita/issues/new?template=fhir_conformance.yml) |
| Request a capability | [Feature request](https://github.com/Ilavrita/Ilavrita/issues/new?template=feature_request.yml) |
| Report a vulnerability | [SECURITY.md](SECURITY.md) — not a public issue |
| Ask about commercial licensing | <oss@ilavrita.health> |

Before filing, check [known limitations](docs/known-limitations.md). Ilavrita is
an early scaffold, and most FHIR interactions are simply not implemented yet
rather than broken.

Ilavrita is maintained by a small team. Community support is best effort and
carries no service-level commitment.
